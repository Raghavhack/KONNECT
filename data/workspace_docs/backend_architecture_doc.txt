KONNECT Backend Architecture and Microservice Specification
Abstract: The KONNECT platform separates ingestion ingestion orchestration from semantic intelligence. The Node.js backend handles OAuth2 authentication with Microsoft Azure Entra ID, registers webhook subscriptions on OneDrive, and dispatches document modification events into a BullMQ Redis queue with a 3000ms debounce quiet window. The Python intelligence service exposes gRPC endpoints (Port 50051) and REST endpoints (Port 8000) for document ingestion and subgraph retrieval. Neo4j stores the entity-relationship graph with vector indexing (384-dim all-MiniLM-L6-v2 embeddings). Redis provides both semantic caching with cosine threshold 0.92 and BullMQ job management. The ROLAND model is bounded to 2-hop neighborhoods during incremental ingestion to ensure predictable real-time latency.
