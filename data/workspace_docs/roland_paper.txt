ROLAND: Graph Learning Framework for Dynamic Graphs
Abstract: Real-world knowledge graphs evolve continuously with new entities and relationships added over time. Static GNNs require retraining from scratch upon every graph update, incurring prohibitive computational overhead. ROLAND introduces a dynamic graph learning framework that maintains per-node hierarchical hidden states across snapshots. In each snapshot t, spatial message passing produces candidate representations ~h_v^(l, t) at layer l (Eq. 5). A Gated Recurrent Unit (GRU) updates the temporal hidden state using previous state h_v^(l, t-1) and candidate ~h_v^(l, t) (Eq. 6). Updated states are fed hierarchically to subsequent GNN layers (Eq. 7). ROLAND is trained using Truncated Backpropagation Through Time (Truncated-BPTT) with bounded memory horizons, enabling efficient online adaptation.
