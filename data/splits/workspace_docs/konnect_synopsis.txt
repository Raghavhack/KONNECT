KONNECT: Real-Time Incremental Knowledge Graph RAG Intelligence Platform
Abstract: Enterprise knowledge systems require continuously updating knowledge graphs as documents are created and edited in OneDrive. KONNECT integrates Microsoft Graph webhooks with a real-time event-driven Python intelligence service. When a document edit arrives, instead of executing a full rebuild taking tens of minutes, KONNECT performs delta extraction, updates affected entities in Neo4j, and invokes a bounded k-hop re-embedding using the ROLAND dynamic GRU framework. For retrieval, KONNECT applies Prize-Collecting Steiner Tree (PCST) optimization over GNN embeddings to assemble minimal connected context. A two-tier Redis semantic cache prevents redundant LLM generation, ensuring sub-second query latency and constant-time incremental updates.
