From Local to Global: A GraphRAG Approach to Query-Focused Summarization
Abstract: Retrieval-Augmented Generation (RAG) approaches typically retrieve isolated text chunks via vector search. However, standard RAG fails when queries require summarizing global concepts across an entire corpus. GraphRAG addresses this by using Large Language Models to extract a hierarchical knowledge graph from source documents. Entities, claims, and relationships are detected and normalized. The graph is subsequently partitioned into modular communities using hierarchical community detection algorithms like Leiden. Each community generates pre-computed summary reports, allowing both global query answering and multi-hop entity traversal. Experiments show GraphRAG substantially outperforms baseline vector RAG on comprehensiveness and diversity metrics.
